# ご利用手順

台本と音声(または動画)ファイルを渡すだけで、テロップ・効果音入りの動画編集データを
自動で作成するツールです。むずかしい設定は不要です。

## 最初に1回だけ行うこと

お使いのパソコンに合わせて、下記のいずれかを行ってください。

### Macをお使いの場合

1. 画面右上の検索(虫眼鏡マーク)から「ターミナル」と入力して開く
2. 次の1行をコピーして貼り付け、Enterキーを押す

```
curl -fsSL https://raw.githubusercontent.com/t12m07duo2017-byte/auto-telop/main/installers/mac/install.sh | bash
```

3. 途中でパスワードの入力を求められた場合は、パソコンのログインパスワードを入力してEnter
   (入力しても画面には表示されませんが、正しく入力されています)
4. 「セットアップが完了しました」と表示されたら完了です

### Windowsをお使いの場合

1. 画面左下の検索から「PowerShell」と入力して開く
2. 次の1行をコピーして貼り付け、Enterキーを押す

```
irm https://raw.githubusercontent.com/t12m07duo2017-byte/auto-telop/main/installers/windows/install.ps1 | iex
```

3. 「セットアップが完了しました」と表示されたら完了です

※ この作業には数分〜十数分かかることがあります(初回のみ)。

## 送られてきたファイルを入れる(最初に1回だけ)

担当者からメール等で送られてきた4つのファイル

- `template.prproj`
- `style_analysis.json`
- `style_se_categories.json`
- `license.key`

を、デスクトップの `AutoTelop` フォルダの中にある `customer_package` フォルダに
そのまま入れてください。

## 使い方(毎回)

1. デスクトップの `AutoTelop` フォルダを開く
2. `入力` フォルダの中に、台本ファイル(色分け済みの.rtfファイル)と、
   音声または動画ファイルを1つずつ入れる
3. デスクトップの `AutoTelop` アイコン(Mac: `AutoTelop.command` / Windows: `AutoTelop.bat`)を
   ダブルクリックする
4. 黒い画面(ターミナル)が開いて処理が始まります。しばらく(数分〜数十分)待つと
   「完了しました」と表示されます
5. 完成したファイルは `出力` フォルダに保存されます

処理が終わったら、画面の案内にしたがってEnterキーを押すとウィンドウが閉じます。

## うまくいかないときは

`docs/トラブルシューティング.md` をご覧いただくか、担当者までご連絡ください。
その際、画面に表示されたメッセージと、案内された「ログファイル」の場所を
一緒にお伝えいただけるとスムーズです。
