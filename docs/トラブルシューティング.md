# トラブルシューティング

## Gatekeeper(Mac)「開発元が未確認のため開けません」と出る

`AutoTelop.command` はインストール時にこのパソコン上で作られたファイルのため、
通常はこの警告は出ません。それでも出てしまった場合:

1. Finderで `AutoTelop.command` を **右クリック(またはControlキーを押しながらクリック)**
2. メニューから「開く」を選ぶ
3. 表示されるダイアログでもう一度「開く」を選ぶ

これで以後は通常どおりダブルクリックで開けるようになります。

## SmartScreen(Windows)「Windows によって PC が保護されました」と出る

1. 表示された画面で「詳細情報」をクリック
2. 「実行」ボタンをクリック

`AutoTelop.bat` はインストール時にこのパソコン上で作られたファイルのため、
通常はこの警告は出ません。繰り返し出る場合は担当者にご連絡ください。

## インストール中に「パスワードを入力してください」と出る(Mac)

Homebrew(必要なソフトを導入する仕組み)のインストールで、パソコンのログイン
パスワードが必要になることがあります。入力しても画面には何も表示されませんが、
そのまま入力してEnterキーを押せば大丈夫です。

## pip / ffmpeg 関連のエラーが出る

- インターネット接続を確認してください(初回セットアップ時はまとまったデータを
  ダウンロードします)
- 一度ターミナル(またはPowerShell)を閉じて、もう一度最初のインストール手順
  (1行コマンド)を実行し直してください
- それでも解決しない場合は、表示されたエラーメッセージの画面をそのまま
  スクリーンショットして担当者にお送りください

## 「ライセンスキーが見つかりません」「ライセンスの確認に失敗しました」と出る

`customer_package` フォルダの中に `license.key` が入っているかご確認ください。
入っているのにエラーが出る場合、ファイルが壊れている可能性があるため、
担当者に再送を依頼してください。

## 「入力フォルダに台本ファイルが見つかりません/複数あります」と出る

`入力` フォルダの中身をご確認ください。台本ファイル(.rtf)は必ず1つだけ
入れてください。前回使ったファイルが残っていないかもあわせてご確認ください。

## RTF台本の色分けが正しく反映されない

- 台本ファイルは必ず「.rtf」形式で保存してください(.txtや.docxではありません)
- 色分けのルールは以下のとおりです。それ以外の色は無視されます

  | 色 | 意味 |
  |---|---|
  | 黒(通常の文字色) | 基本テロップ |
  | 青(文字色) | ネガティブな強調テロップ |
  | 赤(文字色) | ポジティブな強調テロップ |
  | オレンジ(文字色) | 強調テロップ |
  | 緑(背景の色) | その行に画像を1枚配置する |

- 文字色と背景色を間違えている場合があります(例: 背景を赤にしてしまっている等)。
  文字自体の色を変える操作になっているか確認してください

## 音声認識に時間がかかる

動画の長さに応じて、数分〜数十分かかることがあります(パソコンの性能にもよります)。
処理中に黒い画面が固まって見えても、途中経過のメッセージが時々表示されていれば
正常に処理が進んでいます。10分程度動画が動かない・メッセージも一切出ない場合のみ、
一度Ctrl+C(Windowsも同様)で中断し、担当者にご連絡ください。

## それでも解決しない場合

処理が失敗すると、画面に「詳しいログを保存しました」というメッセージとともに
ログファイルの場所が表示されます。そのログファイルを担当者に送っていただくと、
原因の特定がスムーズです。
